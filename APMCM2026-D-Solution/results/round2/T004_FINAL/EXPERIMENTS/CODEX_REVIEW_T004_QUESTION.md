# Codex 核验请求（T004，只读）

请只做数学核验，不修改任何文件。回答用中文，给出明确判定与可写入论文的精确措辞。

## 背景事实（已由归档与本地枚举确认）

1. 原题 Problem 3：在 A（52 个元素）、B（52 个元素）、X∈{O3,NO2,FO2} 中各选一个，使代理模型预测的 V̂(a,b,x) 最小；候选池 8,112 = 52×52×3，全部有预测值。题面要求“model this problem in QUBO form and solve it”。
2. 正式基线 B（`results/reproduction_20261127/predictions/`）下，Q3 全池最小值为 0，共有 6 个并列最优：
   O3：CsTaO3、KNbO3、PbTiO3；NO2：LaZrO2N；FO2：KTiO2F、NaTiO2F。
3. 团队实际做法：固定 X，分别构造并求解 3 个 52×52 的 one-hot QUBO（每个 104 个决策比特 + 1 个辅助自旋），再比较三个子问题的最小 V̂。每个子问题再用 topk=13 预筛为 26 比特后提交硬件。没有提交单个联合 QUBO。
4. 已提交的真机 QUBO 均为 26 比特 one-hot（13 A + 13 B），转为 27 自旋 Ising 后对角为 0、矩阵对称。硬件实际返回样本的辅助自旋全部为 +1。
5. 对 27 自旋 Ising 做全空间精确枚举（2^26 种原始位型，辅助自旋取 ±1）得到：
   - O3：合法最低 H=-2962；aux=+1 子空间内非法最低 H=-2938（差 24）；aux 自由时非法最低 H=-2962（差 0）。
   - FO2：合法最低 H=-2912；aux=+1 子空间内非法最低 H=-2876（差 36）；aux 自由时非法最低 H=-2912（差 0）。
   - Q2 的三个 27 自旋实例同样：aux=+1 间隙 36/36/64，aux 自由时间隙 0。
6. 因此我们准备写出：无外场 Ising 满足 H(s)=H(-s)，任一合法 one-hot 态的全局翻转是非法态且能量相同，故“全空间基态全部合法”不可能成立；只能在 aux=+1 的二进制域内讨论合法性间隙。

## 请核验的四个问题

### Q1 固定 X 分解的精确性
把候选集按 X 分成三个互不相交的切片 S_x。逐切片求 min_{a,b} V̂(a,b,x)，再对 x 取最小。请判定：
- 该做法是否精确等于原问题 min_{a,b,x} V̂？
- 最优集合是否等于三个切片最优集合的并？
- 是否存在任何需要额外假设的边界情况？

### Q2 是否满足“model this problem in QUBO form”
V̂(a,b,x) 对三个 one-hot 组是三线性项 z_x x_a y_b，不能直接写成一个 107 比特的二体 QUBO。团队的固定 X 分解是 3 个 QUBO + 一次有限比较。请判定：
- 这在数学上是否构成原问题的一个精确 QUBO 求解方案？
- 若评审严格要求“单一 QUBO”，下面的复制变量构造是否精确、变量数与约束是否正确：
  对每个 x 复制 A、B 两组变量 x_{x,a}, y_{x,b}（3×52×2=312 比特）；约束 (i) 对每个 x，Σ_a x_{x,a}=Σ_b y_{x,b}；(ii) Σ_x Σ_a x_{x,a}=1；目标 Σ_x Σ_{a,b} V̂(a,b,x) x_{x,a} y_{x,b}，约束以二次罚项并入。
- 请指出该构造是否还需要额外约束（例如同一 x 的 A/B 组必须同时为空或同时选一个），以及是否有更小的精确单 QUBO 表述。
- 若团队没有提交单 QUBO，论文应如何准确表述，既不冒充“单一 QUBO”，也不否定分解的精确性？

### Q3 Z2 对称性与“全空间基态”
请核验：H(s)=-sᵀJs，J 对称且对角为 0，则 H(s)=H(-s)。因此：
- “全空间基态全部合法”是否必然不成立（只要存在一个合法态，其翻转就是非法态）？
- 正确的命题是否应为“全空间基态集合与合法集合相交非空；aux=+1 子空间内合法最低严格低于非法最低”？
- 若硬件返回样本的辅助自旋全部为 +1，能否据此把统计域限定为 aux=+1 子空间？需要什么额外证据才能声称 SDK/平台固定了该位？

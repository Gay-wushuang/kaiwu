# T003-04：PrecisionReducer 的数学验证与边界

- 对象：`B-Q2-NO2` lowM（`mfactor=0.33826009024559534`）为主，Q3 两个输入为对照。
- 数据：`EXPERIMENTS/LOCAL_VALIDATION.json`、`TRUNCATED_GAP_Q2.json`；
  17 个自旋共有 2^17 个赋值，固定辅助位 +1 后为 **2^16 个独立赋值**（枚举时先展开
  2^17 再筛选 aux=+1）。

## 1. 记号与命题

- 原始 one-hot QUBO：`Q`，16 变量；`I = to_ising(Q)`，17 自旋（末位辅助）。
- 截断：`s_bits = max|I| / (2^(b-1)-1)`，`I_b = round(I/s_bits)*s_bits`。
- 变量拆分：`T = c * perform_precision_adaption_split(I_b, param_bit=8, min_increment=s_bits)`
  （`c` 为公共缩放；拆分一致状态满足每组副本相等）。
- 对任意原始自旋 `x`，`construct_split_solution(x, split_indices)` 给出拆分一致扩展态
  `X=Px`。**命题（可行子空间等价，Codex 核验）**：设 `sym(M)=(M+Mᵀ)/2`，
  `H_T(X)=Xᵀ sym(T) X`。恒等式 `H_T(Px)=c·H_{I_b}(x)+K_b` 对所有 `x` 成立
  **当且仅当** `Pᵀ sym(T) P − c·sym(I_b)` 的非对角元全为零；此时 `K_b` 等于该差矩阵
  的迹（另加显式常数项）。每条组内边在一致态上的自旋乘积恒为 1，因此**罚项的符号
  与大小不影响这条恒等式**。要保持最小化排序还需 `c>0`，且 `c` 必须包含公开 split
  可能引入的单位换算（本仓库用常数比例核验求 `c`）。
- 该命题只在可行子空间内成立；它**不证明**“拆分罚项足以让全局最优落在一致子空间”。
  后者需要 `E_C≤E_U`（至少一个一致基态）或 `E_C<E_U`（所有基态一致）。构造最优低于
  采样最小值只是 `E_C` 的一个上界证据，不能给出 `E_U` 的下界；Codex 给出了
  “罚项奖励一致但 0<λ<J 时不一致态更低”的反例框架。

- 合法 vs 非法的能量间隙在各位宽均为正（约 13.815–14.348），说明报告的最低能量来自
  合法态；该间隙不能区分 La-Zr 与 La-Hf，因此另列 `H_b(La-Zr)−min`。
- 只有 9、11、15 位是**严格丢失**（差 >0）；14、17 位是**并列保留**（差 =0，多出并列）。
  两者在“集合相等”口径下都不合格，但在“原始最优是否仍在最优集合”口径下不同。

关键事实：

- 原始最优间隙只有 `0.001396`；截断步长在 13 位时为 0.0074，是间隙的 5.3 倍，
  但 13 位仍唯一保留——说明单看步长不能判定丢失。
- 严格丢失/并列/保留随位数**非单调**（9、11、15 严格丢失；14、17 并列；其余唯一保留），
  符合带符号舍入误差理论：两态能差扰动为 `Σₑ εₑ[φₑ(y)−φₑ(x)]`，每项 `|εₑ|≤s_b/2`，
  但总和可随位宽变号；量化也可能制造并列，而枚举只记录代表标签。
- PrecisionReducer 的 `truncated_precision=tp` 在本机对应有效截断 `tp-1` 位
  （`tp=12→11`、`tp=14→13`、`tp=16→15`）。因此：
  - `tp=12` 严格丢失 Q2 原始最优（11 位，差 0.356）；
  - `tp=14` 唯一保留（13 位）；
  - `tp=16` 严格丢失（15 位，差 0.0074）；
  - `tp=18` 为 17 位，La-Zr 并列保留（差 0，但多出 La-Hf）。
- Q3 的代表标签同样非单调：O3 在 13 位代表 V=0.0010（未核验是否并列），
  FO2 在 11–15 位代表 V 非零（0.0817/0.027/0.0083/0.0386/0.0083），17 位才恢复 0。
  这些是代表标签，不等同于严格丢失；严格判定需逐位计算原最优的劣势与并列集合。

## 3. 拆分嵌入的数值证据

以 Q2 lowM `tp=12` 为例（扩展 62 自旋，17 组）：

- 原始最优（La-Zr，aux=+1）构造的扩展态：拆分一致；能量低于 seed 0/1/2/4 的样本最小值
  （差 284、164、476、720），在 seed 3 与样本最小值持平（差 0），且该 seed 恰有
  1 个拆分一致的合法 V=0 样本。准确表述是“4 个 seed 未搜到、1 个 seed 持平”，
  不能写成“SA 从未搜到”。
- 但 `tp=12` 的有效截断为 11 位，`I_11` 中 La-Zr 严格劣于 La-Hf（差 0.356）。
  因此构造解的 V=0 不是截断问题的全局最优；扩展一致子空间的最优应为 La-Hf。
- seed 3 的 V=0 已有一致样本来源；其余 seed 的 V=0 是否来自不一致样本的恢复，
  需要逐行保留扩展样本与 SDK 恢复结果才能判定，现有汇总量不足以归因。
  因此可以说“V=0 不能全部作为保真证据”，不能说“多来自不一致样本”。

## 4. 小规模全空间验证

教学案例 `V=[[0,0],[1,0.5]]`、`d=2`、`M=17`：

- 原始 Ising 5 维；PrecisionReducer（`precision=4`）扩展为 17 维。
- 用 `BruteForceOptimizer` 枚举扩展问题，PrecisionReducer 恢复出 4 个解，全部解码为
  V=0 的原始最优标签。这验证了**该案例返回解**的原始目标值，不等价于验证
  “所有一致态能量恒等式”或“所有扩展基态一致”。
- 该案例的 `split_indices` 未能用公开 split 接口复现（`mapping_status=unavailable`），
  因此只作为机制演示，不作为映射重建证据。

## 5. 证据等级

| 命题 | 证据等级 |
|---|---|
| 可行子空间等价 `H_T(Px)=cH_{I_b}(x)+K_b` | 数学推导；条件为 `Pᵀsym(T)P−c·sym(I_b)` 非对角为零 |
| Q2 各截断位的最优标签与 La-Zr 劣势 | 2^16 个 aux=+1 独立赋值的全空间枚举 |
| 映射重建 | 候选分组在容差内复现扩展矩阵（Q2 tp12 偏差 1.4e-14）；**不唯一识别内部映射** |
| 拆分一致样本率 | SA 100 样本/seed，5 seeds；非全局性质 |
| “罚项足以让全局最优一致” | **未证明**；构造态 ≤ 采样最小值不构成 `E_U` 下界 |
| 原始最优保留 | 仅对具体截断位成立；14/17 位为并列，9/11/15 位为严格丢失 |
| 小案例恢复 | 仅验证该案例返回解；不构成一般定理 |

## 6. Codex 核验

- `gpt-6.2-astra / xhigh / read-only`，调用 1 次；输出 `EXPERIMENTS/CODEX_REVIEW_01.json`
  （status=REVISE）。主要修正已并入本文：
  - 可行子空间等价的条件形式与常数项；
  - 构造态低于采样值不能证明全局最优一致（给出反例框架）；
  - seed 3 的 V=0 有一致来源，不能归因“多来自不一致”；
  - 截断代表标签 ≠ 严格丢失，需报告 La-Zr 劣势与并列集合；
  - 映射重建是“候选分组复现”，不是唯一识别；
  - 结论只支持“该对照/预算/seed 下 direct8 更优”，不支持跨参数否定 PR。

## 7. 未解决问题

1. 拆分罚项的下界条件：需要给出“任何不一致状态都不能优于一致最优”的可检验不等式；
   当前只有逐实例能量比较。
2. 为什么 SA 的拆分一致率随副本数增加反而下降（`tp=12` 的 3–5 副本高于 `tp=14`
   的 6–9 副本）？需要分析能量地形或罚项/目标耦合比。
3. `only_feasible_solution=True` 在本机无可行解时返回 0 行而非抛异常；这是 SDK 行为
   差异，需在正式流程中自行判定。
4. 若要保留 Q2 原始最优，需要有效截断 ≥13 位（`tp=14`），扩展 121 自旋；若要求
   全部三个输入都保留，需要 17 位（`tp=18`，约 500 自旋）。容量与可搜索性冲突。

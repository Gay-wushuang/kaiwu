## 1. 数学假设

现有 `build_qubo` 默认 `M0=max(2*range,1)+15`，对 B-Q2-NO2 topk=8 为 `42.170953`；它远大于保证 one-hot 合法解优于非法解所需的 `max V = 13.585477`。过大的 M 放大 Ising `max|J|`，降低 8bit 目标分辨率，导致原始最优 La-Zr 在量化后不再是合法最优（第一轮原始命中 0/5 的机制之一）。

候选将 one-hot 罚项降到 `M=1.05*max V=14.264750`（`mfactor=0.33826009024559534`）。对 V≥0 的 one-hot，`M>max V` 保证每个合法解严格优于所有非法解；因此不牺牲全空间约束有效性，同时提高目标分辨率。

## 3. 差异清单（为什么不同实现会差 0.02 的 R²）

1. **目标不同**：直接回归 V 得 R² 0.831；先预测 e_form/gap/vbm/cbm 再按罚项合成得 0.825。
   论文主线用后者（尾部更贴合，池内最低值能到 0.000），附表用前者。
2. **口径不同**：0.825 是 02→03 holdout；15,225 行 OOF 是另一回事，通常略好。
3. **特征不同**：35 维元素描述符（Z/族/周期/电负性/半径/体积/质量 + 差值/和 + X 原子数 +
   A 位与氧的电负性失配 + a_eq_b）。加 one-hot 146 维反而降到 0.809。
4. **gap 处理不同**：96.12% 的带隙为 0，单阶段回归 R² 只有 0.32–0.44；两阶段（分类器 × 回归器）
   在直方图 GBDT 上到 0.513，在 XGBoost 上略降（0.441→0.388）。AUC 0.94。
5. **随机种子与并行**：`random_state=0`、`n_jobs=-1`、`tree_method="hist"`；xgboost 3.x 与 1.x 在
   直方图分箱上与旧版有细微差别，跨大版本复现不必期待小数点后三位一致。

## 4. 公开池 top10 的“V<1”不要当质量证据

07/08 池的候选有 6–8 成在 02+03 里带标签，用这些标签校验等于拿训练数据给自己评分。
实测（我们的排序）：

- Q2 top10：8 个有标签，其中真实 V<1 的 **6** 个
- Q3 top10：6 个有标签，其中真实 V<1 的 **4** 个

所以“9/10、10/10”这类数字只反映泄漏程度，不反映模型好坏。论文里没有用这类指标。

## 5. holdout 上出现精确 0.000 的解释

物理量路线合成 V 时，四项物理量同时落进阈值就输出 0；holdout 里 19 个正例正好在这个区域。
直接回归 V 的模型在同一批数据上最小值是 0.502——两条路线的尾部行为不同，这是设计差异，不是错误。
论文 §3.3 已写明：直接回归“不敢给低值”，物理量路线“尾部贴合”。
